# Synthetic raw ESSENCE-like inpatient admission pull for encounter linkage

A small, fabricated dataset representing a separately queried
`HasBeenAdmitted = 1` ESSENCE query, purpose-built to demonstrate
[`link_encounters()`](https://andrew-farrey.github.io/sysPrep/reference/link_encounters.md)
two-pull linkage in
[`vignette("encounter-linkage")`](https://andrew-farrey.github.io/sysPrep/articles/encounter-linkage.md)
alongside
[essence_ed_raw](https://andrew-farrey.github.io/sysPrep/reference/essence_ed_raw.md).
All facility names, visit identifiers, patient identifiers, and
geographic values are entirely synthetic. No real patient or facility
data are included.

## Usage

``` r
essence_inp_raw
```

## Format

A data frame with approximately 6 rows and 18 columns. Same column
structure as
[essence_raw](https://andrew-farrey.github.io/sysPrep/reference/essence_raw.md);
see its documentation for column definitions.

## Source

Entirely synthetic. Generated by `data-raw/generate_synthetic_data.R`.

## Details

### Visit types included

- Continuity-break admission half:

  2 rows (`HasBeenE = 0`, `HasBeenAdmitted = 1`) sharing
  `HospitalName x Visit_ID` with a real row in
  [essence_ed_raw](https://andrew-farrey.github.io/sysPrep/reference/essence_ed_raw.md)
  – the mis-submitted direct-admit continuation of an ED visit reported
  as two unrelated records.

- Genuine direct admission:

  4 rows (`HasBeenE = 0`, `HasBeenAdmitted = 1`) with a `Visit_ID` that
  appears nowhere in
  [essence_ed_raw](https://andrew-farrey.github.io/sysPrep/reference/essence_ed_raw.md)
  – true direct admissions with no preceding ED visit at all,
  structurally invisible to a `HasBeenE = 1` query.
